Drop your login/signup hero photo here as `hero.jpg` (or update
`HERO_IMAGE_SRC` in `components/auth/AuthShell.tsx` if you'd rather use a
different filename/format).

Recommended: a portrait/landscape shot at least 1200px on the short side —
it's displayed full-bleed with `background-size: cover`, so anything
important should stay away from the edges. It renders behind a dark
gradient + the app's ambient orb accent, so pick an image with enough
contrast for a light foreground element to sit on top of it.
